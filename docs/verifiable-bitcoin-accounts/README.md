# Verifiable Bitcoin Accounts

Verifiable Bitcoin Accounts (VBA) are a way for institutions to use Bitcoin without compromise, enabling deployment in onchain lending and yield markets while preserving existing custody arrangements.

Built on Threshold Network's battle-tested signer infrastructure, Verifiable Bitcoin Accounts (VBA) are purpose-built for custodians, institutional allocators, asset managers, family offices, hedge funds, corporate treasury teams, and other organizations. It delivers segregated custody, verifiable UTXOs, direct access to onchain yield/ lending markets, and a compliant, tax-advantaged pathway to on-chain finance.

Every spending condition is verifiable on-chain and auditable by design.
